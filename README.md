# Histogram Builder

Math 2201 (Unit 5, Section 2 — Histograms and Frequency Polygons) formative practice app.

The table is given; the graph is the work. Students choose the vertical scale
(step and axis maximum, validated for fit and waste), set each bar's height by
dragging or steppers, supply the axis label and title, and get per-bar feedback
(correct / too tall / too short — never the numeric answer). A read-back step
asks two questions from the student's own built graph, and a polygon mode
(`?mode=polygon`) has them plot midpoint points over a faint histogram.

Ten scenarios with fresh random data on every visit; the frequency table —
including the relative-frequency calculation shown per bin — stays beside the
graph the whole time. Single-file HTML, no external dependencies.
